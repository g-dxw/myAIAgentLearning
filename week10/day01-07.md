## Reflection/Self-Correction 模式（面试 Q8 核心）

> **为什么需要：** Agent 生成输出后，可能存在错误或不完整。Reflection 模式让另一个 Agent（或同一个）扮演 Critic，检查输出并提供反馈让前者迭代。

```
提取 Agent → 初步结果
    ↓
Critic Agent → 检查：完整性？一致性？异常标记？
    ↓
如果不通过 → 反馈给提取 Agent → 修正 → 再检查
    ↓
通过 → 进入下一步
```
