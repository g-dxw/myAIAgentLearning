# Week 03 — Agent 核心循环：Function Calling + Tool Use

## 本周目标
理解 Agent 的核心循环机制——手写一遍 Agent Loop：LLM 返回 tool_calls → 执行函数 → 返回结果 → LLM 整合回答 → 循环。产出：一个能调用多个工具的 Agent。

> **重要：** 本周完全不依赖 LangChain/CrewAI 等框架。手写一遍后再用框架。
