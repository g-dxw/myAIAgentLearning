# Week 04 — RAG 原理与实践

## 本周目标
理解 RAG（检索增强生成）的完整流程。产出：**文档问答系统**（上传 PDF/文档 → 问答）。

> **核心理念：** RAG 不是"调个 API + 查个向量库"，而是一套数据处理流水线。本周手写每个环节。

## 主线设计思路

```
Day 01-02 → 理解 RAG 的两个基础组件：Embedding + Chunking
Day 03-04 → 串成完整流水线：Store → Retrieve → Generate
Day 05   → 实战中最大的痛点：检索质量怎么提升
Day 06   → 进阶模式 + 把 RAG 变成可复用工具
Day 07   → 综合产出，一个能用的系统
```
