# Week 08 — MCP + Skills + 协议生态

## 本周目标

从 Week 07 的多 Agent 协作升级到**协议层**。掌握 MCP（Model Context Protocol）标准化工具协议、Skills（可复用能力包）和 A2A/ACP（Agent 间通信协议），产出：**自定义 MCP Server + 一个可复用的 SKILL.md**。

> **核心理念：** Week 06-07 你用 `create_agent` + `@tool` 构建了 Agent。但 `@tool` 是 Python 函数，只能在同一个进程里用。MCP 把工具变成**跨进程、跨语言**的标准协议——你写的 MCP Server 可以被 Claude Code、Cursor、任何 MCP 客户端调用。Skills 则更进一步：不是"工具接口"，而是"可发现、可版本化、可分发的能力包"——告诉 Agent **怎么完成一类任务**。
>
> **⚠️ 大纲更新说明：** 原 Week 08 只讲 MCP 协议。2026 年 Agent 生态已形成 MCP + Skills + A2A/ACP 三层协议体系，故扩展为协议生态专题。

## Skill vs Tool vs MCP vs Prompt（2026 核心区分）

| 概念 | 本质 | 生命周期 | 典型例子 |
|------|------|---------|---------|
| **Tool** | 可调用的函数接口 | 单次调用 | `get_weather(city)` |
| **Prompt** | 一次性指令 | 单次使用 | "你是一个天气助手..." |
| **MCP** | 标准化工具协议 | 跨进程持续 | MCP Server 暴露的 `search_routes` |
| **Skill** | 可复用的能力包 | 可发现、可版本化 | `SKILL.md` 描述的 "code-review" 流程 |

> **面试金句：** Tool 是"手"（可调用接口），Prompt 是"嘴"（一次性指令），MCP 是"神经接口"（标准化外部连接），Skill 是"大脑的知识"（可复用的流程知识）。
