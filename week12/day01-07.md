## 记忆管理深度（面试 Q3/Q9 核心）

> **为什么面试必考：** "Agent 失败不是因为模型不够强，是因为记忆层先崩了。" 2026 年 Agent 工程师路线图明确指出记忆管理是最薄弱环节。

| 记忆类型 | 说明 | 存储方式 | 压缩策略 |
|---------|------|---------|---------|
| **工作记忆** | 当前上下文窗口 | Context Window | Trim / Summary Buffer |
| **情节记忆** | 历史交互记录 | Checkpointer / Store | 递归摘要 |
| **语义记忆** | 用户事实和偏好 | Store / 向量库 | Embedding 检索 |

**压缩策略对比：**

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| **Trim** | 根据语义重要性保留（不只截断） | 保留 System Prompt + 最近 N 轮 |
| **Summary Buffer** | 旧对话摘要化，摘要存入 Context 头部 | 多轮长对话 |
| **递归摘要** | 摘要的再摘要 | 超长会话 |
| **文件系统转储** | 中间结果写文件（Deep Agents） | 需要持久化的任务 |

## Workflow vs Autonomous Agent（面试 Q6 核心）

> **面试金句：** "2026 年的工程趋势是'用 Workflow 约束 Agent'——在框架定义的路径内给予 Agent 局部决策权。"

| 维度 | Workflow | Autonomous Agent |
|------|---------|-----------------|
| 控制流 | DAG / 状态机硬编码 | LLM 决定循环和工具 |
| 可靠性 | 高、可预期 | 低、灵活 |
| 适用 | 报销审批、标准化客服 | 开放式研究、代码编写 |
| 2026 趋势 | 用 Workflow 约束 Agent | 在 Workflow 内局部自主 |
