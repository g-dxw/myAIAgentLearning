## 浏览器 Agent（Agent-Learning-Hub Stage 6 核心）

> **为什么需要：** 有些信息 API 拿不到，需要像人一样"看"网页、"点"按钮。browser-use 基于 Playwright，让 AI Agent 用自然语言指令操控浏览器。

| 能力 | API Tool | 浏览器 Agent |
|------|---------|------------|
| 数据获取 | 结构化 JSON | 需要解析 DOM |
| 适用场景 | 有公开 API 的服务 | 无 API 的网页 |
| 速度 | 快 | 慢（需要渲染） |
| 维护成本 | 低（API 稳定） | 高（页面变化） |
| 安全风险 | 低 | 高（可能误操作） |

**安全限制：**
- 不登录敏感账号（银行、支付）
- 不越权操作
- 不绕过平台规则（如反爬虫）
- 记录截图、DOM、动作日志

## 沙箱代码执行（2026 Agent 工程师必备）

> **为什么需要：** Agent 生成的代码不能直接在宿主服务器执行——可能包含恶意操作、可能消耗过多资源、可能访问敏感数据。沙箱隔离是安全底线。

| 方案 | 特点 | 适用场景 |
|------|------|---------|
| **E2B** | 云端沙箱，开箱即用 | 快速原型、不需要本地资源 |
| **Modal** | Serverless 函数，可定制 | 生产环境、需要特定依赖 |
| **Docker** | 本地隔离 | 开发环境、完全可控 |
| **Claude Code 沙箱** | 内置安全边界 | Claude Code 内部 |
