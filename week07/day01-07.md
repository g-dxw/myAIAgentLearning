# Week 07 — 多 Agent 协作系统

## 本周目标
从 Week 06 的单 Agent 升级到多 Agent 协作。掌握 2026 年 LangChain 官方四大模式（Subagents / Handoffs / Skills / Router）和 Deep Agents 高层框架，产出：**多 Agent 徒步出行规划系统**（路线专家 + 天气专家 + 装备专家 + 规划主 Agent 协作）。

> **核心理念：** Week 06 你用 `create_agent` 搭了一个"什么都能干"的单 Agent。但当一个 Agent 工具太多、上下文太长、领域太杂时，它就开始"犯傻"——选错工具、忘记上文、推理混乱。多 Agent 的本质是**上下文工程**：给每个 Agent 只看它需要的信息，让它在自己的专长领域做到最好。
>
> **⚠️ 大纲更新说明：** 原 Week 07 大纲是"CrewAI + Agent 间通信"。2026 年 LangChain 官方已推出完整的多 Agent 体系（四大模式 + Deep Agents），比 CrewAI 更主流、与 Week 06 无缝衔接，故改为官方体系。

## 四大模式速查（2026 官方）

| 模式 | 核心机制 | 适合场景 | 并行 | 用户直接交互 |
|------|---------|---------|------|------------|
| **Subagents** | 主 Agent 把子 Agent 当 tool 调用 | 多领域、需并行、集中控制 | ⭐⭐⭐⭐⭐ | ⭐ |
| **Handoffs** | 状态驱动，Agent 间交接控制权 | 多轮对话、状态流转 | - | ⭐⭐⭐⭐⭐ |
| **Skills** | 单 Agent 按需加载专门知识 | 简单聚焦任务、单 Agent 够用 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| **Router** | 路由分类后分发给专门 Agent | 分类明确、可并行 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |

## 与 Week 06 的衔接

| Week 06（单 Agent） | Week 07（多 Agent） |
|--------------------|-------------------|
| 一个 Agent 干所有事 | 多个专长 Agent 分工协作 |
| `create_agent(model, tools)` | 主 Agent + 多个子 Agent（也是 create_agent） |
| 所有工具塞给一个 Agent | 每个子 Agent 只有自己的工具 |
| 单一上下文，越来越长 | 上下文隔离，每个 Agent 只看需要的 |
| 无文件系统、无长期记忆 | Deep Agents 带文件系统 + Memory + Skills |

Week 06 的 `create_agent` 是本周的基石——每个子 Agent 都是用 `create_agent` 创建的。本周把它从"一个"变成"一群"，从"全能"变成"专精"。
