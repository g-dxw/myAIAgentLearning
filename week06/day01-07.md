# Week 06 — LangChain + LangGraph

## 本周目标
从手写 Agent Loop（Week 03）升级到用框架编排 Agent。掌握 LangChain 的模型/工具抽象与 LCEL，再用 LangGraph 的状态图编排多步推理。产出：**多步推理 Agent**（路线推荐 → 天气查询 → 装备清单 → 出行建议）。

> **核心理念：** Week 03 你手写了 `while True: call → parse → execute → append` 的 Agent Loop。本周用 LangChain + LangGraph 把这个循环"工程化"——状态管理交给 State，控制流交给 Graph，持久化交给 Checkpointer。但框架不是黑盒：因为你手写过，所以用框架时你知道每一行在干什么。

## LangChain / LangGraph / LangSmith 三者关系

```
LangChain   = 组件层：模型/工具/Prompt/输出解析的抽象与集成
LangGraph   = 编排层：状态图、持久化执行、人机交互、流式（本周重点）
LangSmith   = 可观测层：追踪、评估、调试（本周副线调试时用）
```

> LangGraph 可以脱离 LangChain 单独用，但配套 LangChain 的模型/工具抽象最顺手。本周用 LangChain 做组件，用 LangGraph 做编排。
