# Week 06 — LangChain + LangGraph

## 本周目标
从手写 Agent Loop（Week 03）升级到用框架编排 Agent。掌握 LangChain 的**新 `create_agent` 高层 API**（基于 LangGraph 内置），理解 Agent 背后的 StateGraph 结构，学会记忆持久化、人机交互、流式输出。产出：**多步推理 Agent**（路线推荐 → 天气查询 → 装备清单 → 出行建议）。

> **核心理念：** Week 03 你手写了 `while True: call → parse → execute → append`。本周用 LangChain + LangGraph 把这个循环"工程化"——但框架不是黑盒：因为你手写过，所以用框架时你知道每一行在干什么。
>
> **⚠️ 重要：** 2026 年 LangChain 已重构——官方推荐用 `create_agent()` 替代手写 LCEL + while 循环。它内置了 LangGraph 的 Agent Loop，一行代码即可创建带工具循环、Checkpointer、流式输出的完整 Agent。

## 与 Week 03 / Week 05 的衔接

| Week 03（手写 Agent） | Week 06（框架编排） |
|--------------------|------------------|
| `while True` 手写循环 | `create_agent()` 一行创建 → 内置 LangGraph 循环 |
| 手动解析 tool_calls | LangChain `bind_tools` + `ToolMessage` 自动处理 |
| 手动管理 messages list | State + reducer + Checkpointer 自动管理 + 持久化 |
| 无持久化，重启即丢 | Checkpointer(`InMemorySaver`) + Store 双层次记忆 |
| 错误处理手写 try/except | ModelRetryMiddleware / ToolRetryMiddleware 内置重试 |
| 无流式支持 | `stream_events(version="v3")` 带中断恢复的流式 |

| Week 05（向量库） | Week 06（Agent 框架） |
|------------------|---------------------|
| 徒步路线知识库语义搜索 | 多步推理 Agent 调用路线检索工具 |
| 向量检索是"能力" | Agent 框架把多个能力编排成"流程" |
