# Week 09 — Agent 评测 + 可观测性 + 安全

## 本周目标

从"能跑"升级到"能评、能观测、能防御"。掌握 Agent 评估体系（成功率/步数/工具准确率）、可观测性工具（Langfuse/LangSmith trace）、安全防御（Prompt Injection / 权限隔离 / 沙箱执行），产出：**Agent 评估表格（20+ 任务）+ 安全审计报告**。

> **核心理念：** Week 06-07 你搭了能跑的 Agent，Week 08 让它连接了外部世界。但没有评估、没有 trace、没有安全边界的 Agent 只能算 Demo。2026 年 Agent 工程师的核心能力不是"能搭 Agent"，而是"能证明 Agent 可靠、能定位故障、能防御攻击"。
>
> **⚠️ 大纲更新说明：** 原 Week 09 只讲"评估指标 + Prompt 版本管理"。2026 年面试高频考点（Q12 Agent 性能量化、Q14 权限隔离）和 Agent-Learning-Hub Stage 7 要求加入可观测性 trace + 安全防御，故大幅扩展。

## Agent 评估指标体系（面试 Q12 核心）

| 指标 | 说明 | 怎么测 |
|------|------|--------|
| **任务成功率** | 核心指标，任务是否完成 | 固定测试集，人工/LLM 判定 |
| **平均推理步数** | 步数越少成本越低 | trace 记录 agent loop 轮数 |
| **工具调用准确率** | 选对工具的比例 | trace 记录 tool_calls vs 期望 |
| **成本** | Token 消耗 + API 费用 | trace 记录 usage |
| **延迟** | 首 token 时间 + 总时间 | 计时 |
| **Shadow Testing** | 新旧 Agent 并行对比 | 生产环境双跑 |

---

## 安全防御体系

| 威胁 | 说明 | 防御方式 |
|------|------|---------|
| **Prompt Injection** | 用户输入注入恶意指令 | 输入过滤 + 系统提示隔离 |
| **Tool Abuse** | Agent 滥用工具（如删库） | Human-in-the-loop 确认 + 权限分级 |
| **Data Exfiltration** | Agent 泄漏敏感数据 | 输出过滤 + PII 检测 |
| **权限越界** | RAG 返回越权数据 | ACL 元数据 + 用户 Filter 注入 |
| **代码执行风险** | Agent 写的代码直接跑 | E2B/Modal 沙箱隔离（概念了解） |
