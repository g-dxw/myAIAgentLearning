# Week 05 — 向量数据库

## 本周目标
深入向量数据库的内部原理与生产级特性。从 Week 04 的"会用 Chroma"升级到"懂原理、能选型、会调优、可部署"。产出：**徒步路线知识库语义搜索系统**。

> **核心理念：** Week 04 把向量数据库当黑盒用——`add` / `query` 就完事。本周拆开黑盒：ANN 算法怎么工作、HNSW 参数怎么调、百万级数据怎么扛、Chroma / Milvus / Qdrant / Pinecone 怎么选。懂了内部，你才知道为什么慢、为什么召回低、什么时候该换库。

## 与 Week 04 的关系

| Week 04（RAG 实践） | Week 05（向量数据库专题） |
|--------------------|------------------------|
| 把 Chroma 当黑盒：`add` / `query` | 拆开黑盒：ANN / HNSW 怎么工作 |
| 单机原型，几百条数据 | 生产级：百万级、分布式、量化压缩 |
| 只用过 Chroma 一个库 | 横向对比 Chroma / Milvus / Qdrant / Pinecone |
| 检索质量优化（Query 改写 / Re-rank） | 检索引擎本身的优化（索引参数 / 量化） |
| 文档问答系统 | 路线知识库语义搜索 |

Week 04 解决"检索质量怎么提升"，Week 05 解决"检索引擎怎么选、怎么调、怎么扛规模"。两个维度叠加，你的 RAG 才算真正落地。
